# MarineFlow 아키텍처 및 구현 범위

## 적용 업무
해양환경조사의 현장 시료 등록부터 분석업체 인수인계, 시험분석성적서 수령, 보고서 작성까지의 데이터 흐름을 다룹니다.

시료 인수 여부를 반복 확인하던 현장 경험을 바탕으로 별도 MVP를 구현했습니다. 예제는 가상 데이터이며 이전 업무 시스템의 원본 코드는 포함하지 않습니다.

## 처리 흐름
~~~mermaid
flowchart TD
A[시료 등록] --> B[인수인계 기록]
B --> C[CSV 분석성적서 업로드]
C --> D{식별자와 분석 항목 검증}
D -->|오류| E[담당자 확인 필요]
D -->|검증| F[보고서 반영 가능 수치]
G[과거 보고서 및 지침] --> H[로컬 검색]
H --> I[근거 포함 보고서 초안]
F --> I
I --> J[연구원 검토 및 최종 승인]
~~~

## 왜 이 기술을 선택했나
| 업무 | MVP 구현 | 향후 설계 |
|---|---|---|
| 현장 시료·인수인계 | Streamlit + SQLite | 인증·권한·감사로그·전자서명 |
| 분석결과 수령 | CSV 파싱 | PDF/HWP OCR 및 추출 검증 |
| 수치 및 ID 확인 | Python 규칙 + SQL | 분석방법·검출한계·단위 변환 |
| 과거 보고서 조회 | 로컬 TF-IDF 검색 | 원문 출처 및 권한을 반영한 RAG |
| 자연어 질의 | 미구현 | Intent Router와 자연어 SQL |
| 보고서 작성 | 검증 데이터 Markdown 템플릿 | AI Agent 및 Doc Write 연동 |
| 최종 승인 | 검토 체크리스트 | 역할 기반 승인 워크플로 |

파수 AI의 Doc Search ACE, Data Query ACE, Doc Write ACE는 **개념적으로 적용을 검토한 후보 솔루션**입니다. 실제 제품 연결, 인증, 라이선스 및 API 제공 여부는 별도 확인이 필요합니다.

A-03-2026Q2의 T-N 누락은 **가상의 시연 상황**이며 실제 측정이나 고객 프로젝트 데이터가 아닙니다. AI는 환경 인과관계와 법적 적합성을 판정하지 않습니다.
